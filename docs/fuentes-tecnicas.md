# Fuentes técnicas consultadas

- [Android UsageEvents.Event](https://developer.android.com/reference/android/app/usage/UsageEvents.Event): semántica de estados de pantalla, bloqueo, actividad y reinicio.
- [WorkManager: definición de trabajo](https://developer.android.com/develop/background-work/background-tasks/persistent/getting-started/define-work): periodicidad mínima y ejecución diferida.
- [SDK Android 16](https://developer.android.com/about/versions/16/setup-sdk): compile/target API 36.
- [Flutter SDK archive](https://docs.flutter.dev/install/archive): versión Flutter 3.35.7 fijada en esta construcción.
- [SQLCipher para Android](https://github.com/sqlcipher/sqlcipher-android): integración de Room con SupportOpenHelperFactory, cifrado real de base.
- [FastAPI en contenedores](https://fastapi.tiangolo.com/deployment/docker/): construcción de imagen propia y proceso API.
- [SHAP TreeExplainer](https://shap.readthedocs.io/en/latest/generated/shap.TreeExplainer.html): contribuciones aditivas del modelo.

La documentación técnica guía APIs y compatibilidad; no es evidencia de que el laboratorio detecte depresión. La bibliografía académica original no se revalidó en esta implementación y no se usa para atribuir significado clínico a umbrales o métricas sintéticas.
